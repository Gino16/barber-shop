🚀 CARGAR DATOS
────────────────

Opción 1: SQL (PostgreSQL)
  $ psql -U barber_shop -d barber_shop -f scripts/seed-items.sql

Opción 2: CURL (API REST)
  $ bash scripts/curl-examples.sh

Opción 3: Postman
  1. Import → scripts/postman-collection.json
  2. Ejecutar requests desde la UI

Opción 4: Manual (Un item a la vez)
  $ curl -X POST "http://localhost:8080/api/items?page=1&pageSize=10" \
      -H "Content-Type: application/json" \
      -d '{"name": "...", "description": "...", "category": "SERVICE", "active": true}'


🔍 CONSULTAS ÚTILES
────────────────────

Ver todos:
  GET /api/items?page=1&pageSize=100

Solo servicios:
  GET /api/items?page=1&pageSize=100&category=SERVICE

Solo productos:
  GET /api/items?page=1&pageSize=100&category=PRODUCT

Buscar "fade":
  GET /api/items?page=1&pageSize=100&search=fade

Buscar "pomada" en productos:
  GET /api/items?page=1&pageSize=100&search=pomada&category=PRODUCT

Ordenar por nombre:
  GET /api/items?page=1&pageSize=50&sortBy=name&sortDirection=desc
